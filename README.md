# AstrBot 图像生成插件

面向 AstrBot 的通用图像生成插件，支持多供应商、文生图、图生图、LLM 工具调用、限流和每日额度。

## 功能

- 多供应商：支持 OpenAI、Gemini、Grok、Jimeng2API、Gitee AI、SiliconFlow、火山方舟等图像生成接口。
- 文生图与图生图：可识别消息图片、引用消息图片和 @ 用户头像作为参考图。
- LLM 工具调用：可作为 LLM 工具在对话中自动触发生图。
- 稳定性控制：支持多 API Key 轮询、重试、并发限制、频率限制和每日额度。
- 使用限制白名单：可直接填写完整 UMO、QQ号或群号。

## 命令

| 命令 | 说明 |
| :--- | :--- |
| `/生图 <提示词>` | 根据提示词生成图片。消息、引用消息或 @ 用户头像可作为参考图。 |
| `/生图模型` | 查看可用模型和当前模型。 |
| `/生图模型 <序号>` | 切换到指定序号的模型。 |

## 常用配置

### LLM 工具

| 配置名 | 默认值 | 说明 |
| :--- | :--- | :--- |
| 启用 LLM 工具 | 生图工具 | 选择是否允许 LLM 调用生图工具。 |

### 生成设置

| 配置名 | 说明 |
| :--- | :--- |
| 生图完成后引用原消息 | 开启后，生成完成发送图片时引用触发 `/生图` 或 LLM 工具调用的原消息；关闭后直接发送图片。 |
| 开始任务时发送固定图片 | 开启后，触发生图任务时会在开始提示中附带固定图片。 |
| 开始任务固定图片路径 | 本地图片绝对路径或 http(s) 图片 URL，可与开始生图任务提示模板文字同时发送。 |

### 用户限制配置

| 配置名 | 说明 |
| :--- | :--- |
| 会话黑名单 | 黑名单会话无法使用指令和 LLM 工具。支持完整 UMO、QQ号或群号匹配。 |
| 管理员无视使用限制 | AstrBot 管理员跳过会话黑名单、频率限制和每日额度，但仍记录每日用量。 |
| 使用限制白名单 | 可填写完整 UMO、QQ号或群号；命中后跳过会话黑名单、频率限制和每日额度，但仍记录每日用量。 |
| 黑名单拒绝提示 | 黑名单命中时返回的文本，留空则不提示。 |
| 速率限制 | 单个会话两次请求之间的最小间隔；0 表示不限。 |
| 启用每日额度 | 开启后按会话统计每日生成次数。 |
| 每日允许生成数量 | 开启每日额度后，每个会话每天可生成的最大数量。 |
| 最大参考图大小 | 限制用户上传/引用参考图的大小。 |

## 使用限制白名单填写方式

`使用限制白名单` 支持三种写法：

```text
完整 unified_msg_origin（UMO）
QQ群号
QQ号
```

示例：

```json
"umo_whitelist": [
  "aiocqhttp:GroupMessage:123456789_987654321",
  "123456789",
  "987654321"
]
```

说明：

- 填完整 UMO：只匹配该具体会话。
- 填群号：匹配该群相关会话。
- 填 QQ号：匹配该用户相关会话。

> 配置字段名仍保留为 `umo_whitelist`，用于兼容旧配置；界面显示名称已改为“使用限制白名单”。

## 已移除功能

以下功能已从配置模板和运行逻辑中移除：

- 安全审核
- 图片审核
- 提示词模板
- 预设/人设相关命令与 LLM 工具

## 使用示例

普通生图：

```text
/生图 一只赛博朋克风格的猫
```

切换模型：

```text
/生图模型
/生图模型 2
```

## 重载

修改配置后，请在 AstrBot 中重载插件或重启 AstrBot。
