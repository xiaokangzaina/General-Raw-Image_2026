# 通用生图 General Raw Image 2026

这是一个给 AstrBot 使用的生图插件，仓库地址是 https://github.com/xiaokangzaina/General-Raw-Image_2026。

这个版本主要按个人使用习惯维护，重点是接入多个图片生成渠道，让群聊或私聊里发起生图更顺手。它保留了常用能力，删掉了不再维护的预设、人设和审核相关功能，配置也尽量收拢到实际会用到的部分。

## 能做什么

插件可以根据文字描述生成图片，也可以结合已有图片继续生成。用户可以直接在聊天里发起生图，也可以让 AstrBot 的模型在合适的时候调用生图能力。

它支持把消息里的图片、引用消息里的图片、被提到用户的头像作为参考图。生成任务可以限制频率、控制每日次数，也可以给指定群或指定用户放行。

生成开始时，机器人可以先回一句提示，也可以顺带发一张固定的等待图。生成完成后，可以选择引用原消息再发图，也可以直接发送结果。

## 安装

推荐从 Release 下载插件压缩包安装。打开仓库的 Release 页面，下载最新的 astrbot 插件压缩包，然后在 AstrBot 的插件管理里选择本地安装。安装完成后，重载插件或重启 AstrBot。

如果你的 AstrBot 支持从仓库安装，也可以直接填写本仓库地址：

https://github.com/xiaokangzaina/General-Raw-Image_2026

如果本机以前装过 astrbot_plugin_image_generation，建议先卸载旧插件，再安装这个版本。这样后续更新来源会指向本仓库，不会再被识别成原来的上游插件。

## 日常使用

在聊天里发送“斜杠生图 加上你的描述”即可开始生成图片。想查看模型列表，可以发送“斜杠生图模型”。想切换模型，可以在命令后面加模型序号。

例如，你可以让它画一只赛博朋克风格的猫，也可以引用一张图片后再说明想怎么改。插件会把可用的参考图收集起来，再交给当前配置的图片渠道处理。

## 配置说明

生图模型决定默认使用哪个渠道和模型。默认宽高比、默认分辨率可以留为不指定，这样请求里不会强行带上比例或清晰度参数，交给上游模型自行处理。

最大并发任务数用于控制同一时间能跑多少个生图任务。并发开太大可能会触发上游限制，也可能让机器人回复变慢。

显示生图信息开启后，生成完成会带上耗时、图片数量等信息。显示模型信息开启后，结果里会说明这次用的是哪个模型。

生图完成后引用原消息适合群聊使用，方便看出图片是回应哪条消息。完成回复文本可以自定义，如果留空，就只引用原消息并发送图片。

开始生图任务提示模板用于任务刚开始时的回复。可以写成简短提示，比如“开始画了，稍等一下”。如果不想发文字，就留空。

开始任务固定图片适合放等待图、加载图或提示图。可以只填一张图片，也可以填多张图片。多张图片支持按顺序轮流发送，也支持随机发送。图片来源可以是本地绝对路径，也可以是网络图片地址。

LLM 工具开关用于决定是否允许 AstrBot 的模型主动调用生图。本版本只保留生图工具，不再保留预设查询和预设编辑工具。

## 使用限制

使用限制总开关开启后，插件会对普通会话执行黑名单、频率限制和每日额度检查。白名单里的群或用户会跳过这些限制。关闭总开关后，所有会话都会直接放行。

会话黑名单用于禁止某些群或用户使用生图。命中黑名单时，机器人会返回你配置的拒绝提示。

管理员无视使用限制开启后，AstrBot 管理员不会受到黑名单、频率和每日额度限制。

使用限制白名单支持三种写法：完整 UMO、QQ群号、QQ号。填写完整 UMO 时，只放行那个具体会话；填写群号时，放行相关群聊；填写 QQ 号时，放行相关用户。

速率限制用于限制同一个会话两次生图之间的间隔。每日额度用于限制每个会话每天最多能生成多少次。最大参考图大小用于避免用户上传过大的图片拖慢任务或占用过多资源。

## 已移除的内容

这个版本已经移除安全审核、图片审核、审核白名单、提示词模板、预设提示词、人设模板、预设命令，以及预设和人设相关的 LLM 工具。

如果你需要这些旧功能，不建议直接把旧配置复制进来。插件会尽量兼容历史配置，但已经移除的功能不会再按旧逻辑工作。

## 文件位置

adapter 目录放各个图片供应商的适配逻辑。core 目录放任务、配置、日志等核心逻辑。main.py 是插件入口。metadata.yaml 是 AstrBot 识别插件用的元数据。_conf_schema.json 是插件管理页里看到的配置模板。requirements.txt 写插件依赖。README.md 是这份说明。LICENSE 是许可证。
