# 通用生图 General Raw Image 2026

这是一个适用于 AstrBot 的通用图像生成插件。它的目标很简单：让机器人可以在群聊或私聊中稳定地接收文字描述、参考图片和头像，然后调用不同图片生成服务返回结果图。

项目仓库：
https://github.com/xiaokangzaina/General-Raw-Image_2026

## 插件定位

本插件面向日常聊天场景，不追求复杂的模板系统，而是把常用生图流程做得更直接。你可以把它理解为 AstrBot 的统一生图入口：用户只需要说明想画什么，插件负责整理参数、收集参考图、提交任务、下载图片并发回聊天。

当前版本重点保留了真正会用到的能力，例如文字生图、参考图生图、引用图片生图、头像参考、任务提示、生成完成回复、使用限制、每日额度和多渠道适配。过旧、维护成本较高或容易造成混淆的预设、人设、审核模板等内容已经移除。

## 主要能力

插件支持通过聊天命令发起图片生成。用户可以输入描述，让机器人生成一张或多张图片。也可以引用一张已有图片，再描述想要调整的方向，让插件把引用图片作为参考交给上游模型。

插件可以读取消息中的图片、引用消息中的图片，也可以在需要时使用被提到用户的头像作为参考图。多个参考来源会在任务提交前进行整理，避免重复传入同一张图片。

插件支持多种图片生成服务。不同服务的连接方式、模型名称、默认比例和分辨率可以在配置中管理。默认宽高比和默认分辨率可以保持为“不指定”，这样插件不会强行给上游接口附加额外限制。

插件支持任务开始提示。生图开始后，机器人可以先回复一段文字，也可以发送固定等待图。等待图可以是一张，也可以是多张。多张等待图可以按顺序轮换，也可以随机发送。

插件支持生成完成后的回复控制。你可以让结果引用原消息，方便群聊里判断图片回应的是哪条请求；也可以设置完成提示文本，或者只发送图片本身。

插件支持基本使用限制。可以设置黑名单、白名单、速率限制、每日额度和最大参考图大小。管理员可以选择不受这些限制影响。

插件支持 AstrBot 的大模型工具调用。开启后，AstrBot 的语言模型可以在合适的时候主动调用生图工具。本版本只保留统一生图入口，不再保留预设查询、预设编辑和人设相关工具。

## 安装方式

推荐从 GitHub Release 下载压缩包安装。进入本仓库的 Release 页面，下载最新的插件 zip 文件，然后在 AstrBot 插件管理中选择本地安装。安装完成后，重载插件或重启 AstrBot。

如果你的 AstrBot 支持从仓库安装，也可以直接填写仓库地址：
https://github.com/xiaokangzaina/General-Raw-Image_2026

如果本机曾安装过旧插件 astrbot_plugin_image_generation，建议先卸载旧插件，再安装本插件。这样可以避免 AstrBot 把它识别成旧来源，也能减少配置迁移时的混乱。

## 基本使用

在聊天中发送生图命令并附上描述即可开始生成。你可以描述画面主体、风格、光线、构图、颜色和细节。描述越清楚，生成结果越接近预期。

想查看可用模型，可以使用模型列表命令。想切换模型，可以按照插件提示选择模型序号或名称。具体命令以 AstrBot 加载插件后显示的帮助信息为准。

如果想基于已有图片生成，可以发送图片并附带说明，也可以引用一张图片后提出修改要求。插件会尽量把可用图片整理为参考图，再交给当前选择的模型处理。

## 配置说明

配置中最重要的是图片服务渠道。你需要先根据自己使用的服务填写连接地址、密钥、模型名称和能力类型。不同渠道支持的能力不同，有的只支持文字生图，有的支持参考图或图片编辑。

默认模型用于决定没有特别指定时使用哪个生图渠道。默认比例和默认分辨率建议先保持不指定，除非你明确知道上游模型支持哪些值。

最大并发数用于控制同时运行的生图任务数量。并发过高可能触发上游限流，也可能让机器人响应变慢。日常使用建议从较小数值开始。

开始任务提示适合写短句，例如“开始画了，请稍等”。如果不想在任务开始时回复文字，可以留空。固定等待图适合放加载图或提示图，支持本地路径和网络地址。

生成结果展示信息可以按需开启。开启后，机器人会在结果中显示耗时、图片数量或所用模型等信息。关闭后，回复会更简洁。

使用限制总开关开启后，普通会话会受到黑名单、频率和每日额度约束。白名单会话和管理员豁免可以跳过限制。每日额度适合公开群聊，能避免插件被连续刷屏。

最大参考图大小用于保护机器人运行环境。过大的图片会占用更多内存和网络时间，建议根据服务器性能合理设置。

## 已移除内容

本版本已经移除旧的安全审核、图片审核、审核白名单、提示词模板、预设提示词、人设模板、预设命令，以及预设和人设相关的大模型工具。

这些内容不会再作为主要功能维护。旧配置中如果仍然存在相关字段，插件会尽量兼容或忽略，但不会恢复旧逻辑。建议不要直接把早期版本的完整配置复制到新版本中。

## 文件说明

adapter 目录用于放置不同图片服务的适配逻辑。

core 目录用于放置配置、任务、图片处理、日志、用量统计和工具调用等核心逻辑。

main.py 是插件入口文件。

metadata.yaml 是 AstrBot 识别插件名称、版本、作者和仓库地址的元数据文件。

_conf_schema.json 是插件配置页面使用的配置结构说明。

requirements.txt 记录运行插件所需的 Python 依赖。

README.md 是本说明文档。

CHANGELOG.md 是版本更新记录。

logo.png 是插件头像。

## 注意事项

插件能否生成图片，取决于你配置的上游图片服务是否可用。若出现生成失败，请优先检查密钥、接口地址、模型名称、网络状态和额度限制。

不同模型对比例、分辨率、参考图数量和图片格式的支持并不一致。遇到失败时，建议先使用最简单的文字生图测试，再逐步加入参考图和高级参数。

公开群聊中建议开启频率限制和每日额度。这样可以减少刷屏，也能降低上游服务额度被快速消耗的风险。
